# TouchXbox

把 Android 手机或兼容 Android 的鸿蒙手机、平板变成可编辑的悬浮手柄，向本机提供手柄和键盘输入。支持 Xbox、NS、PS 和 FPV USB HID 遥控器协议。

首次安装首页为空，从右上角 **＋** 创建或导入模板。桌面名称可随协议切换为 **TouchXbox / TouchNS / TouchPS / TouchFPV**，也可固定选择。项目使用 Apache-2.0 许可证。

## 安装与启动

默认使用 **电脑 USB + 独立 CMD 授权**，Shizuku 入口暂时隐藏。

1. 在 [最新发布页](https://github.com/Zhgma/TouchXbox/releases/latest) 下载 APK，安装到手机或平板。
2. **开启开发者模式**：华为 / 鸿蒙 4.2 进入“设置 → 关于手机（或关于平板）”，连续点击“版本号”7 次，按提示输入锁屏密码。其他设备可在设置中搜索“版本号”。
3. **开启 USB 调试**：进入“设置 → 系统和更新 → 开发人员选项”，打开“USB 调试”。找不到时可在设置中搜索。
4. **连接电脑**：用支持数据传输的 USB 线连接 Windows 电脑，保持手机解锁，在“允许 USB 调试”弹窗中点“允许”。弹窗也可能在运行下一步的 CMD 后出现。
5. **电脑运行授权脚本**：下载 [TouchXbox-authorize.cmd](https://github.com/Zhgma/TouchXbox/releases/latest/download/TouchXbox-authorize.cmd)，双击运行。该文件与 APK 在同一发布页提供，可独立使用；电脑没有 ADB 时会自动下载，首次使用需联网。运行前请保存正在编辑的模板。
6. 电脑显示“输入服务激活成功”后，回到应用允许悬浮窗权限，创建并保存模板，点击模板启动。

应用内 **齿轮 → 电脑 USB 授权（默认）** 提供完整步骤、CMD 下载链接和复制链接按钮。CMD 需要在 Windows 电脑运行；手机上下载的文件需先传到电脑。

激活后可以拔掉 USB。新版 CMD 将输入后台保存为独立运行文件，正常覆盖更新可复用已有授权；从旧脚本切换需运行一次新版 CMD。手机重启、清除应用数据或输入服务退出后，仍需连接电脑运行 CMD。应用更新可通过 **齿轮 → 关于 → 检查更新** 完成。

## 功能介绍

- **模板管理**：点按启动，长按编辑、删除或复制配置；拖动卡片右上角把手排序。名称保留左侧，右下角原启动三角形替换为对应协议的圆角 logo。
- **快捷启动**：长按模板设为快捷启动，同时只能开启一个；桌面图标和名称跟随它，点击图标直接启动或展开遥控。长按桌面图标选择“打开软件”，或点击运行通知，即可返回模板和设置。取消或删除目标模板后恢复原来的图标设置。
- **布局编辑**：全屏预览中拖动控件；位置和尺寸可随设备等比适配，保留控件横纵比；模板可设置仅横屏启用。
- **按键和摇杆**：固定或跟随摇杆、长按摇杆键、多种方向键与 ABXY 样式、肩键尺寸和位置联动、滑出后保持按下。
- **键盘输入**：从键盘布局多选添加，统一调整大小；控件可删除、恢复、自定义名称和点按高亮名称。
- **悬浮收起**：点击模板中规划的收起区域，收进系统贴边气泡，点气泡展开。系统气泡能力取决于设备支持。
- **图标和名称**：自动跟随已激活协议，或在设置中固定为 Xbox、NS、PS、FPV、原始 TouchXbox 图标。
- **传感器**：采集本机加速度计、陀螺仪，生成 NS / PS 体感报告；后续软件能否读取还取决于系统驱动与软件支持。
- **FPV 操控习惯**：编辑 FPV 模板时点选任一摇杆，可切换下表三种模式。默认保持原来的美国手。两杆都是正方形范围；油门初始最低，上下不回中，再次触摸从上次油门位置继续；其他轴松手回中。

| FPV 模式 | 左摇杆 | 右摇杆 |
| --- | --- | --- |
| 美国手（默认，Mode 2） | 左右偏航，上下油门 | 左右横滚，上下俯仰 |
| 日本手（Mode 1） | 左右偏航，上下俯仰 | 左右横滚，上下油门 |
| 中国手（Mode 3） | 左右横滚，上下俯仰 | 左右偏航，上下油门 |

配置可复制成字符串分享，在首页 **＋ → 粘贴配置** 导入。0.5.7 导出的配置需使用 0.5.7 或更新版本导入；旧模板默认沿用美国手。
